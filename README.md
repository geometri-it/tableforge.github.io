# 🎲 TABLEFORGE — Modern Board Games

> **Choose the game. Build the night. Make the table yours.**

TABLEFORGE is a modern tabletop storefront concept built around game discovery and the experience created around the table.

The project is intentionally more than a product grid. It organizes the catalog around **players, play time, complexity, category and experience**, making it easier to find a game that fits the moment.

## Shopping bag

The storefront uses browser `localStorage` to maintain a client-side shopping bag.

Supported actions:

- Add product
- Remove product
- Track quantities
- Calculate subtotal
- Persist the bag during navigation
- Display product imagery
- Open a demo checkout action

The checkout is intentionally not connected to a payment processor.

## Image standard

The storefront uses a consistent visual system:

- Square product frames.
- Centered presentation.
- Clean compositions.
- No website screenshots.
- No price overlays.
- No buttons inside product photography.
- No UI elements embedded into product images.
- Local image files.
- Consistent crop and resolution.
